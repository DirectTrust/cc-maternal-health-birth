# cc-maternal-health-birth

Implementation Guide for the **cc-maternal-health-birth** use case, built on the DirectTrust Framework for Metadata and Payloads via the Direct Standard®.

No version of this guide has been released yet, so this branch is intentionally empty. The guide is under development on the [`develop`](https://github.com/DirectTrust/cc-maternal-health-birth/tree/develop) branch; its draft is published at https://directtrust.github.io/cc-maternal-health-birth/develop/.

This branch keeps only the GitHub Actions workflow (`.github/workflows/deploy.yml`) that publishes the site. The workflow runs the build scripts from `develop`. When the first version is ready, merge `develop` into `main` and publish a GitHub release.
