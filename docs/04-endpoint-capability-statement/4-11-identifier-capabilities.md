# 4.11 Identifier Capabilities

Publish identifier namespaces the endpoint actually produces, recognizes, or requires for matching and correlation. Do not publish a generic list merely because an identifier type appears elsewhere in the guide.

| **Identifier role** | **Namespace** | **Produce** | **Recognize** | **Required** |
|----|----|----|----|----|
| Patient / Person | Endpoint-specific | Yes / No | Yes / No | Yes / No |
| Organization | Endpoint-specific | Yes / No | Yes / No | Yes / No |
| Provider | NPI and/or other | Yes / No | Yes / No | Yes / No |
| Visit Context Instance | Applicable namespace | Yes / No | Yes / No | Yes / No |
| Perinatal Context Instance | Applicable namespace | Yes / No | Yes / No | Yes / No |
| Request Context Instance | Applicable namespace | Yes / No | Yes / No | Yes / No |
