# 8. Reference Notes Retained

The source design records used to develop this guidance should be retained as Reference Notes. They preserve the evolution and detailed rationale behind the published guidance: the Identifier Handshake, CDA Document Construction Principles, and Workflow Task Module for Direct XDM Exchange. The publication files reorganize and normalize those ideas but do not eliminate the value of the original design records.
