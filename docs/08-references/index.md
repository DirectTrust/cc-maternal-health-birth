# References and Related Implementation Guides

_Supporting standards and reusable implementation guidance_

Use these references to understand the standards, information models, and reusable exchange capabilities applied by Care Coordination for Maternal Health – Birth. Apply this guide’s common requirements and the applicable Transaction Definition together with the requirements of the relevant source standard or implementation guide.

| **Guide or Standard** | **Read It for Information About** | **Relationship to Implementation** |
|----|----|----|
| Metadata and Payloads Framework for Direct | Common exchange concepts, metadata, packaging, actors, correlation, and Provenance. | Common framework concepts and requirements underpin the transaction, metadata, packaging, and Provenance rules in this guide. |
| AMIA Patient Naming Framework | Consistent representation and interpretation of patient names. | Supports consistent patient-name interpretation in identification and matching workflows. |
| Workflow Status via Direct | Reporting acceptance or rejection of a structured payload into its intended workflow. | Provides reusable guidance for the TX8 acceptance and rejection reporting pattern described in Chapter 3. |
| Event Notifications Via Direct | Exchange of event notifications and their supporting metadata. | Provides event-notification guidance used with the applicable event-notification Transaction Definitions. |
| Update Patient Matching Information Via Direct | Communicating changes to patient-matching information. | Provides reusable guidance for communicating patient-matching information updates under the applicable Transaction Definition. |
| Send Documents Via Direct | Document exchange and its common packaging and workflow requirements. | Provides reusable guidance for document exchange, applied with this guide’s maternal-health content requirements. |
| HL7 V2 version 2.5.1 | Message structures and event semantics. | Provides the source message model for applicable event-notification workflows. |
| HL7 CDA R2 | Clinical document structure, header, narrative, and entries. | Provides the clinical document architecture for exchanged CDA information objects. |
| HL7 FHIR R4 | Resources and serialization used for metadata, Task, Provenance, and packaging. | Provides the resource model for FHIR metadata, Task, Provenance, and structured payload packaging. |
| HL7 CDA R2 Consolidated CDA | Reusable clinical document and section templates. | Provides applicable clinical document and section template constraints. |
| HL7 CDA R2 C-CDA Companion Guide | Companion implementation guidance for C-CDA. | Supports consistent application of applicable C-CDA implementation requirements. |
| HL7 CDA R2 C-CDA Supplemental Guidance for Pregnancy | Pregnancy-specific clinical document and content guidance. | Provides pregnancy-specific content guidance relevant to the clinical documents exchanged in this use case. |
| IHE Perinatal Workflow | Perinatal information exchange and workflow guidance. | Provides perinatal exchange and workflow guidance relevant to the maternal-health scenarios. |
