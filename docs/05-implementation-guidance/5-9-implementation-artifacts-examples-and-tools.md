## 5.9 Implementation Artifacts, Examples, and Tools

Use the published terminology and artifacts, Endpoint Capability Statements, Transaction Definitions, mappings, and illustrative examples together. Examples demonstrate selected requirements; they do not replace the specification, prove full conformance, or make every optional element shown mandatory. Whole-sample files and prototypes are supporting test material, not transaction identifiers or normative dependencies.

Test tools may assist with selecting a transaction, resolving endpoint capabilities, preparing information objects and metadata, constructing the Direct message, and inspecting workflow status reports. Validate their outputs against the specifications and declared endpoint capabilities. A successful package-construction test does not establish end-to-end interoperability or complete profile conformance.
