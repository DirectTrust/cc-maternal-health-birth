# 5.11 Where to Go Next

Use the following references to locate the conceptual explanations and implementation requirements relevant to your task.

| **If you are trying to…** | **Go to…** |
|----|----|
| understand why a document is modeled as a particular information collection | Appendix A |
| understand patient, organization, encounter, Context Instance, or status identity | Appendix B |
| understand XD classification concepts | Appendix C |
| understand the FHIR Collection Bundle packaging model in greater depth | Appendix D, applied with Chapter 3 and the applicable Transaction Definition |
| understand common transaction mechanics | Chapter 3 — Transaction Framework |
| understand endpoint capability or discovery | Chapter 4 — Endpoint Capability and Discovery |
| build, test, or operationalize an implementation | Chapter 5 — Implementation Guidance |
| implement a specific reusable transaction | the applicable Reusable Transaction Definition |
