# How to Use This Guide

The five primary chapters explain the use case and its implementation requirements. Terms and Definitions establishes common language. Each Transaction Definition specifies a Shared Activity. The appendices provide supporting details, and References identifies the resources on which this guide builds. Illustrative examples demonstrate the requirements without replacing their specifications.

Begin with the use-case objectives and participants, then select the workflow and applicable transactions. Apply Chapter 3’s common requirements together with each Transaction Definition. Consult Terms and Definitions for common language and the appendices for supporting mappings and details.

Use the implementation guidance to configure an endpoint that supports some or all of the functionality defined for the cc-maternal-health-birth use case. Create a Capability Statement describing the endpoint’s supported transactions, Technical Actor Roles, and applicable requirements, and publish it at an accessible URL. Include that URL in the endpoint’s SERV_INFO field in the DirectTrust Aggregated Directory so other participants can discover its capabilities and determine whether it is an appropriate Routing Target for an exchange. Make sure that any endpoint Direct addresses included in the Directory are tagged as supporting the cc-maternal-health-birth use case in the associated SERV_DESC field.
