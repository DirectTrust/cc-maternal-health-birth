# What This Guide Defines and Reuses

Care Coordination for Maternal Health – Birth defines a new Send Birth Notification transaction, for communicating information about a newborn to the mother’s care team.

TX6, Query for Documents, is a placeholder for query-based requests and retrieval of documents available for a patient. It represents an exchange performed outside Direct and is not a specified Direct transaction in this guide.

The maternal-health workflows also use reusable transactions for outpatient visit, hospital registration, hospital or ED admission, and hospital or ED discharge notifications; document exchange; patient matching information updates; and workflow status reports. These transactions are organized through the MAP Reusable Transaction Catalog (MAP RTC). Their applicable Transaction Definitions specify the information and processing requirements for each exchange. This guide supplies the maternal-health clinical, Context, participant, and routing requirements.
