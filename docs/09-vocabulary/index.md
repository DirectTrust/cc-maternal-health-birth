# Vocabulary

_DirectTrust value sets_

This catalog lists the 19 ValueSet resources in the DirectTrust Terminology and Artifacts Package V5.1 dated October 12, 2026. Use the names and canonical URL suffixes to locate their definitions in the package. Each description is reproduced exactly from the corresponding ValueSet definition. Applicable terminology bindings are specified in the guide and transaction requirements.
