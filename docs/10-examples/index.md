# Examples

_Mimi Shell snapshot example catalog_

The Mimi Shell example set follows a synthetic maternal health journey from early pregnancy through postpartum care. Use this catalog to locate clinical documents, source forms, and event notification examples at each point in the journey. Folder names below match the snapshot folders in the example package.

Successive snapshots support comparison of information over time. Where listed, transaction packages provide FHIR and XD representations for examining how documents and notifications are packaged for exchange.
